# Dataset Card — RAB Synthetic Evidence Abstention v1

## Summary
A fully synthetic, deterministic dataset of 5,000 evidence episodes generated by the RAB v0.1.0 simulator using five fixed seeds.

## Intended use
- Reproduce the RAB v0.1.0 baseline.
- Test simple evidence-aware answer/abstain policies.
- Demonstrate risk/coverage and condition-level analysis in Kaggle or Google Colab.

## Not intended for
- Training or evaluating production LLMs as if it were real user data.
- Clinical, legal, financial, or other high-stakes decision-making.
- Claims about real-world hallucination or agent safety.
- Benchmark leaderboards without disclosing the synthetic generation process.

## Provenance
Generated locally by `src/rab/benchmark.py`. No personal data, scraped content, external dataset, or real tool transcript is included.

## Rows and fields
Expected default release: 5,000 rows, 1,000 episodes per seed, five seeds.

| Field | Meaning |
|---|---|
| `episode_id` | Stable identifier combining seed and row index |
| `seed` | Random seed used for this episode |
| `evidence_condition` | Synthetic evaluator label: sufficient/missing/irrelevant/contradictory |
| `evidence_present` | Whether the simulated tool returned any evidence |
| `source_count` | Number of simulated evidence sources |
| `evidence_relevance` | Synthetic relevance score in [0, 1] |
| `evidence_consistency` | Synthetic cross-source consistency score in [0, 1] |
| `answerable_label` | Evaluator-only binary label |
| `answer_correct_if_attempted` | Simulated correctness outcome if an answer is attempted |

## Label leakage warning
`evidence_condition`, `answerable_label`, and `answer_correct_if_attempted` are ground-truth/evaluation fields. They must not be used as policy inputs. The included policy implementation intentionally reads only evidence presence, relevance, and consistency.

## Limitations
The dataset is synthetic and reflects explicit assumptions in the experimental protocol. It is not a sample of real tool evidence and does not represent a naturally occurring distribution.
